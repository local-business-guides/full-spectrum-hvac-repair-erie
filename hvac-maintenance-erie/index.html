How to Prepare for an HVAC Checkup

Before the visit, note when the system was last looked at, if you know, and list any changes you’ve noticed since then. You can also gather equipment information or past service notes if they’re easy to find. Don’t worry if you don’t have a full service history; a clear description of what you’ve observed is useful too.

Use this quick preparation list:
- Make a note of sounds, smells, or airflow changes you’ve noticed.
- Identify rooms where the temperature or airflow seems different.
- Clear a path to the indoor and outdoor equipment.
- Write down questions about operation, upkeep, or any recommendation.

Avoid blocking the equipment area or waiting to mention a concern until the end of the visit. Also, don’t assume a maintenance appointment will resolve a known failure. If the system has stopped working or is behaving in a way that worries you, explain that when you call so the concern can be addressed directly.
